# SaYes — Discover • Meet • Play • Join • Create • Enjoy

**SaYes** est la plateforme universelle d'activités sociales — sports, jeux, sorties, rencontres, tournois, loisirs, tout en une seule app.

## 12 Moteurs

| # | Moteur | Rôle |
|---|--------|------|
| 1 | **City** | Pays → Province → Ville → Quartier |
| 2 | **Universal Activity Engine** | Un schéma unique pour TOUS les types d'activités |
| 3 | **Tournament** | Équipes, matchs, classements, prix |
| 4 | **City Map** | Carte interactive temps réel |
| 5 | **Places** | Restaurants, bars, clubs, terrains, piscines |
| 6 | **Games** | Chasse au trésor, quiz urbain, défis |
| 7 | **People** | Profils, amis, groupes, dating |
| 8 | **IA** | Crée n'importe quelle activité en une phrase |
| 9 | **Business** | Pros, billetterie, réservations, promo |
| 10 | **Points / Badges** | Niveaux, achievements, classements |
| 11 | **Chat** | Messages directs + salles d'activité |
| 12 | **Notifications** | Alertes temps réel |

## Stack
- Next.js 14 + TypeScript + Tailwind
- Firebase (Firestore, Auth, Storage)
- Zustand • Google Maps • Anthropic Claude
- Vercel

## Démarrage

```bash
npm install
cp .env.local.example .env.local
npm run dev
```
